## 2. 方法與環境

### 2.1 實驗環境與模型配置

- **被評測端側 SLM**：`citrus-slm`（本機端側小模型，透過 Ollama API 本地推理，模擬手機離線環境）
- **檢索架構**：Pocket Hybrid RAG（N-Gram 關鍵字 + 128 維向量餘弦相似度，Top-K = 2，閾值 = 0.20）
- **知識庫來源**：`plant_diseases_kb.json`（8 筆柑橘重點病蟲害）
- **評估裁判 LLM**：Google Gemini 2.5 Flash（`gemini-2.5-flash`）
- **裁判向量模型**：Google Gemini Embeddings（`models/gemini-embedding-001`，維度 3072）
- **評估框架**：RAGAs v0.4.3

### 2.2 測試資料集結構（12 題分組）

- **【IN_DOMAIN】柑橘病蟲害與用藥核心題（8 題）**：
    1. 潰瘍病火山口特徵與銅劑/防風防治
    2. 潰瘍病禁用大生粉（殺真菌劑對細菌無效）鑑別
    3. 黑點病枯枝產孢與清園禁堆樹下原則
    4. 油斑病葉背氣孔侵入與由下往上噴藥技巧
    5. 煤煙病治煤先治蟲與窄域油物理洗滌
    6. 潛葉蛾捲葉後阿巴汀內滲補救
    7. 小黃薊馬採收前安全採收期（PHI）規範
    8. 介殼蟲窄域油物理窒息與天敵澳洲瓢蟲
- **【CROSS_DOMAIN】跨作物干擾題（2 題）**：
    1. 水稻稻熱病紡錘形病斑與三賽唑防治
    2. 茶樹茶輪斑病同心輪紋與通風排水
- **【OUT_OF_DOMAIN】非農業防幻覺拒答題（2 題）**：
    1. 程式撰寫（Python Quick Sort 拒答）
    2. 天氣查詢（台北天氣與雨具拒答）

### 2.3 評測指標與計算函式

- **Faithfulness（回答真實度／防幻覺）**：`from ragas.metrics import Faithfulness`；計算回答中的陳述句有多少比例能由檢索 Context 完全推導證實，杜絕模型胡編農藥與病徵。
- **Answer Relevancy（回答相關性）**：`from ragas.metrics import AnswerRelevancy`；裁判根據 SLM 回答反推生成 3 個問題，並以 `gemini-embedding-001` 計算與原始問題的餘弦相似度。
- **Context Precision（檢索精確度）**：`from ragas.metrics import LLMContextPrecisionWithReference`；評估檢索出的 Top-2 文本中，真正有用的段落是否排在最前面（Top-1 命中加權）。
- **Context Recall（檢索召回率）**：`from ragas.metrics import LLMContextRecall`；評估專家標準答案中的事實要點，有多大比例被檢索文本完整涵蓋。

## 3. 數據與分析

### 3.1 實測核心優勢（Strengths）

1. **邊界防禦與防幻覺拒答率 100%（OOD Safety）**：面對 Python 寫程式（Q11）與台北天氣查詢（Q12），模型在未命中知識庫時均堅定禮貌拒答，展現極佳角色邊界自覺。
2. **核心病害診斷精準**：潰瘍病（Q1）精確診斷並命中 77% 氫氧化銅；小黃薊馬（Q7）命中安全採收期 6 天；介殼蟲（Q8）命中 95% 窄域油物理窒息機制。

### 3.2 發現之關鍵瓶頸（Weaknesses & Bottlenecks）

1. **Prompt 複誦問題（Prompt Echoing）**：Q3（黑點病枯枝）與 Q9（水稻）出現模型原樣抄寫 Prompt 後未作答即結束之現象（端側 SLM 注意力衰退）。
2. **化學藥劑幻覺（Chemical Hallucination）**：Q2 誤將殺真菌劑大生粉當成「銅類殺蟲劑」；Q4 油斑病拼湊出「95% 狐丘油/精礎油」等不存在藥劑。
3. **跨作物強行套用（Cross-Domain Interference）**：Q10 茶樹問題檢索到柑橘油斑病，模型強行關聯並捏造「茶树柑橘病害」與「代森錳丹」。

### 3.4 後續 SFT 與 RAG 優化策略

1. **Prompt 結尾錨點（Anchor Token）**：在 Prompt 尾部固定加入「【專家診斷與建議】：」強制模型直接進入解答模式。
2. **SFT 微調集強化農藥專用詞**：導入本專案 SFT 資料集，強制模型對齊標準農藥清單，消除幻覺。
3. **加入跨作物拒答樣本**：微調集加入水稻/茶樹/芒果樣本，訓練模型即使撈出柑橘切片也能自主判定並拒答。

## 4. 結論與限制

本次 RAGAs 評估驗證了端側 SLM 在防幻覺拒答與核心病害診斷上的可用性，同時定位出 Prompt 複誦、化學藥劑幻覺、跨作物誤用三項待改善問題，已規劃對應的 Prompt 與 SFT 優化方向。
