## Flutter

```jsx

```

目錄結構：

```jsx
[Flutter project]
├── android/               # Android 原生專案配置與程式碼
├── ios/                   # iOS 原生專案配置與程式碼
├── lib/                   # Flutter 主要核心程式碼 (Dart)
│   └── main.dart          # 應用程式主要入口檔案
```

### 開發者最常使用的目錄與檔案

1. **lib/ （90% 以上開發時間在此處）**
    - 所有 Dart 程式碼（介面 UI、業務邏輯、API 連線、AI 模型呼叫等）都在這個資料夾中。
    - 目前只有預設的 。隨專案擴展，您會在此處建立不同的模組資料夾。
        
        **main.dart**
        
2. **pubspec.yaml**
    - **套件管理**：新增第三方套件（如相機功能 `camera` / `image_picker`、網路請求 `dio` / `http`、本地儲存 `shared_preferences` 等）。
    - **資源宣告**：包含本地圖片、柑橘病蟲害辨識示範圖、圖示（Assets）與字型設定。
3. **android/ 與 ios/ 平台資料夾**
    - **權限設定**：因為病蟲害辨識 APP 需要使用「相機」與「相簿」，您需要在這兩個目錄設定存取權限：
        - Android: `android/app/src/main/AndroidManifest.xml`
        - iOS: `ios/Runner/Info.plist`
    - **App 命名與圖示**：設定 Android/iOS 的 APP 顯示名稱、圖示 (App Icon) 與開場畫面 (Splash Screen)。
4. **test/**
    - 撰寫自動化測試，確保病蟲害辨識邏輯或 UI 組件運作正常。

#### assets資料夾

### `assets` 與 `lib` 的主要差異

| **比較項目** | **`lib/` (程式碼區)** | **`assets/` (靜態資源區)** |
| --- | --- | --- |
| **主要內容** | 僅存放 **Dart 程式碼檔案** (`.dart`)。 | 存放 **多媒體與靜態檔案** (如 `.jpg`, `.png`, `.json`, `.tflite`, `.ttf` 等)。 |
| **功能職責** | 撰寫 **應用程式邏輯**、介面 UI 繪製、網路 API 呼叫與辨識邏輯。 | 提供 APP 所需的 **靜態素材與資料** (如圖片、圖鑑預設圖、AI 模型檔、字型)。 |
| **編譯處理** | 構建 APP 時會被 Dart 編譯器**編譯為二進位執行碼**。 | 構建 APP 時會以**原始檔案形式打包進 APP 安裝包**。 |
| **使用方式** | 透過 `import` 直接引用程式碼。 | 需在 **pubspec.yaml** 宣告後，透過路徑字串讀取 (如 `Image.asset('assets/images/citrus_canker.jpg')`)。 |

### 本專案中，`assets` 資料夾會用來裝什麼？

對柑橘病蟲害辨識 APP 而言，常見的使用場景包括：

1. **病蟲害預設圖片與圖鑑** (`assets/images/`)
    - 柑橘常見病蟲害（如黃龍病、潰瘍病、銹蜱、紅蜘蛛等）的預設範例圖與圖鑑縮圖。
    - APP 標誌 (Logo)、預設大頭貼、引導頁說明圖。
2. **離線 AI 辨識模型** (`assets/models/`)
    - 如果您打算支援**離線辨識**，TensorFlow Lite 模型檔 (`model.tflite`) 與標籤檔 (`labels.txt`) 都會放在這裡。
3. **離線防治資料庫 / JSON** (`assets/data/`)
    - 各種病蟲害對應的農藥/物理防治建議說明 JSON 檔（方便離線時無網路也能查閱）。

### 如何在專案中建立與配置 `assets`？

1. **建立資料夾**： 在專案根目錄 **test** 下新建一個 `assets` 資料夾，並根據分類建立子目錄：
    
    ```
    test/
    ├── assets/
    │   ├── images/         # 柑橘病蟲害圖片、UI 圖示
    │   ├── models/         # (選用) TensorFlow Lite 病蟲害辨識模型
    │   └── data/           # (選用) 防治資訊 JSON 檔
    ├── lib/
    └── pubspec.yaml
    ```
    
2. **在 pubspec.yaml 中宣告**： Flutter 預設不會自動打包未宣告的檔案。您需要在 `pubspec.yaml` 中取消註解或新增 `assets:` 區域：
    
    ```
    yaml
    flutter:
    uses-material-design:true
    
    assets:
        -assets/images/
        -assets/models/
        -assets/data/
    ```
    

這樣在 **lib/** 的程式碼中就能順利載入這些靜態資源了！

#### 自動保護

- **開發/測試時 (`flutter run`)**：自動在終端機印出耗時、收集數據，並可在畫面上按下 `「匯出 CSV」` 按鈕產出 Excel 報表。
- **發布正式版時 (`flutter build apk --release`)**：`kReleaseMode` 斷路器自動生效，AOT 編譯器將計時與 UI 程式碼死碼消除 (Dead Code Elimination)，**這段程式碼直接 0 效能損耗，連一個位元組的記憶體都不佔用**！
