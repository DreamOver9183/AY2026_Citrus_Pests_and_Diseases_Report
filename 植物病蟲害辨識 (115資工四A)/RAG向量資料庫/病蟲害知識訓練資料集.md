# 病蟲害知識訓練資料集

準備訓練資料集（Dataset Preparation）是整個微調流程中**決定模型成敗最關鍵的一步**。如果資料品質不好、格式不對或知識偏頗，模型微調後容易出現答非所問或「幻覺（Hallucination）」現象。

以下為你詳細拆解如何從頭到尾建立一份高質量的「柑橘病蟲害 SFT 微調資料集」：

### 一、 資料集的架構設計（黃金比例）

要打造一個既懂柑橘專業知識、又不會亂回答其他領域問題的專用模型，你的資料庫需要包含以下**兩種數據類型**：

```
整體訓練資料集 (建議 2,000 ~ 5,000 筆)
 ├── 1. 核心專業問答數據 (占比 80%~85%)：柑橘病蟲害診斷、病徵、防治特效藥、田間管理。
 └── 2. 領域防護與拒絕數據 (占比 15%~20%)：非柑橘農業問題、閒聊、程式碼或無關領域的拒絕回答。
```

### 二、 資料集格式詳解（ShareGPT / JSONL 格式）

LLaMA-Factory 極度推薦使用 **JSONL（JSON Lines）** 格式，每行都是一個獨立的 JSON 物件。目前最通用且支援度最好的是 **`ShareGPT` 對話格式** 或 **`Alpaca` 格式**：

#### 1. 核心專業問答範例（正向資料）

包含單輪與多輪對話，訓練模型掌握精準知識：

JSON

```
{"messages": [{"role": "user", "content": "柑橘黑星病主要危害哪些部位？症狀為何？"}, {"role": "assistant", "content": "柑橘黑星病主要危害果實與葉片。受害果實表面會出現圓形、直徑約2-5毫米的斑點，邊緣呈紅色至深褐色，中央稍微凹陷並呈灰褐色。後期病斑中央會長出微小的黑色小粒點。"}]}
{"messages": [{"role": "user", "content": "果園發現柑橘木虱該怎麼處理？"}, {"role": "assistant", "content": "柑橘木虱是傳播黃龍病的媒介昆蟲。防治方法包括：1. 萌芽期密切監測；2. 發現時可噴灑推薦之幾丁質抑制劑或有機磷藥劑；3. 清除果園週邊的繁星花等替代宿主。"}]}
```

#### 2. 領域防護數據範例（Guardrails / 拒絕回答資料）

強迫模型在面對非柑橘領域時，主動「承認不知道」或「禮貌拒絕」：

JSON

```
{"messages": [{"role": "user", "content": "請問水稻稻熱病要噴什麼藥？"}, {"role": "assistant", "content": "抱歉，我的專業領域僅限於柑橘類（如椪柑、檸檬、文旦等）樹葉病蟲害的診斷與防治，無法為您提供水稻病害的建議。"}]}
{"messages": [{"role": "user", "content": "幫我寫一段 Python 網頁爬蟲程式碼。"}, {"role": "assistant", "content": "我是柑橘病蟲害防治 AI 助手，僅提供柑橘類植物相關的農業防治諮詢，無法提供程式撰寫服務。"}]}
```

### 三、 如何高效產生這 2,000+ 筆訓練資料？（黑盒數據蒸餾）

純靠人工筆筆撰寫 2,000 筆資料耗時費力，最成熟的做像是利用 **GPT-4 / Claude 3.5 Sonnet 進行「合成數據生成（Synthetic Data Generation）」**：

**1.準備權威文本源：**

確定知識邊界。

收集農業委員會（農藥所/農業改良場）公開的柑橘病蟲害防治手冊、診斷圖鑑 PDF 文字。

**2.編寫黑盒蒸餾 Prompt：**

丟給 GPT-4 批量生產。

將農藥手冊段落餵給 GPT-4，並使用以下 Prompt 模板自動生成多樣化的問答對：

**3.自動化生成 JSONL：**

導出並檢查格式。

透過 Python 腳本調用 OpenAI API 跑批次處理，自動把產出的文本儲存為 `citrus_disease.jsonl`。

> **💡 GPT-4 資料生成 Prompt 模板：**
> 
> 
> *「你是一位柑橘農業專家與數據集生成器。請閱讀以下關於【柑橘油斑病】的官方介紹文本，模擬農民提問的各種口吻（包含口語化、專有名詞問法、簡短問法），產生 10 組高質量的問答對，並輸出為標準的 JSONL 格式。」*
> 

### 四、 資料清洗與品質控制（Data Cleaning）

在輸入 LLaMA-Factory 訓練前，務必進行以下三個檢查，否則會影響模型表現：

- **1. 控制長度（Cutoff Length）**：
    
    確保單筆問答的總 Token 數不要超過 **512 個 Token**。太長的文字會增加顯存開銷，且與你手機端的離線設定（`n_ctx = 512`）不匹配。
    
- **2. 去除格式錯誤**：
    
    確保 JSONL 每一行都是合法的 JSON 語法，不能有換行符號（`\n`）破壞結構。
    
- **3. 避免矛盾答案**：
    
    同一種病害（如黑星病）的防治藥劑，在不同資料庫條目中的說法要維持一致，避免模型學習時產生困惑。
    

### 五、 於 LLaMA-Factory 註冊資料集（最容易錯的一步）

準備好 `data/citrus_disease.jsonl` 後，必須告訴 LLaMA-Factory 該如何讀取它。

打開 `LLaMA-Factory/data/dataset_info.json`，在最下方新增對應配置：

JSON

```
"citrus_disease_dataset": {
  "file_name": "citrus_disease.jsonl",
  "formatting": "sharegpt",
  "columns": {
    "messages": "messages"
  }
}
```

完成這步後，打開 LLaMA-Factory 的 WebUI 介面，你就能在 **Dataset 下拉選單** 中直接看到並勾選 `citrus_disease_dataset` 進行訓練了！
