# RAG向量資料庫

為 Android 裝置打造本地優先的向量資料庫與 RAG 系統，支援樹葉病蟲害辨識的語意搜尋、知識庫建立與離線使用。

使用的技術為 SQLite + FTS5 + sqlite-vec，並且搭配本地大語言模型（Qwen 2.5 0.5B  GGUF）推理，提供使用者病蟲害防治建議。
