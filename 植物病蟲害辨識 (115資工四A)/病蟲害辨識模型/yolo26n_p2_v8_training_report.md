## 1. 摘要

- 本報告針對 **YOLO26n-P2 (v8)** 於 `Citrus_YOLO26_Detect` 資料集（訓練集 21,014 標註、驗證集 2,250 標註）之訓練過程與驗證表現進行客觀評估。
- 模型在 **Epoch 69** 達到驗證最佳指標：mAP@0.5 = **82.08%**、mAP@0.5:0.95 = **64.69%**、Precision = **80.17%**、Recall = **79.97%**。
- 採用 `patience=30` 於第 100 輪早停，總訓練耗時約 **4.32 小時**（15,536.8 秒），平均每輪耗時 156.94 秒。
- 8 類病蟲害中，Sooty_Mold (AP 0.980)、Oily_Spot (AP 0.978)、Black_Spot (AP 0.934) 表現最優；Thrips (AP 0.572, Recall 53.91%) 與 Citrus_Leaf_Miner (AP 0.748) 為主要定位與召回瓶頸。

## 2. 方法與環境

### 2.1 超參數配置

```python
epochs=160                  # 設定週期上限
imgsz=640                   # 輸入影像尺寸，對應 P2 特徵圖 160x160
batch=32                    # 批次大小
patience=30                 # 早停容忍度（實際於 Epoch 100 觸發早停）
optimizer=MuSGD             # 優化器：μP 架構微步隨機梯度下降法
lr0=0.008                   # 初始學習率
lrf=0.01                    # 最終學習率比例（Cosine 衰減至 lr0*0.01）
momentum=0.937              # 動量係數
cos_lr=True                 # 餘弦退火排程
warmup_epochs=3.0           # 預熱輪次
mosaic=0.7                  # 拼圖增強機率
close_mosaic=30             # 關閉拼圖：最後 30 輪停用 Mosaic
box=8.0                     # 邊界框損失權重
cls=0.8                     # 分類損失權重
dfl=1.5                     # 分佈焦點損失權重
```

### 2.2 模型與訓練架構

- **模型架構**：YOLO26n-P2（針對微小病蟲害目標引入 P2 高解析度特徵層之輕量檢測架構）
- **任務類型**：目標檢測 (`detect`)
- **預訓練權重**：`yolo26n.pt`
- **輸入尺寸**：$640 \times 640$（對應 P2 特徵圖 $160 \times 160$）
- **總訓練時間**：$15,536.80\text{ 秒}$（約 $4.32\text{ 小時}$），平均每輪耗時 $156.94\text{ 秒}$

## 6. 瓶頸分析與誤差診斷

### 6.1 優勢類別

1. **Sooty_Mold (煤煙病)**：Recall 達到 $100.00\%$，Precision $96.88\%$，AP@0.5 高達 $0.980$。因呈大面積黑色斑狀紋理，與葉片背景對比強烈，無漏檢現象。
2. **Oily_Spot (油斑病)** 與 **Black_Spot (黑斑病)**：AP 分別達到 $0.978$ 與 $0.934$，F1 均高於 $85\%$，特徵提取穩定。

### 6.2 主要瓶頸與錯誤源分析

1. **Scale_Insect (介殼蟲) 的高偽陽性 (FP = 615)**：
   - 介殼蟲為樣本量最大類別（真實標註 $1,453$ 個，模型預測 $1,912$ 個）。
   - 偽陽性率 FPR 達到 $39.30\%$，主要來自葉片上的微小反光點、灰塵或木栓化組織被誤判為介殼蟲，導致單類別 Accuracy 降至 $74.45\%$。
2. **Thrips (薊馬) 的高偽陰性 (FN = 106)**：
   - 薊馬 Recall 僅 $53.91\%$（AP@0.5 為 $0.572$），為全類別最低。
   - 混淆矩陣顯示 $104$ 處真實薊馬被漏檢（判定為背景），主因薊馬體型極為微小且常隱匿於葉脈褶皺，P2 層特徵仍存在部分感受野邊界遺失。
3. **Thrips 與 Aphid 間的微量相互誤判**：
   - 混淆矩陣中薊馬與蚜蟲存在 $5$ 處相互誤判（$3$ 隻蚜蟲誤判為薊馬，$2$ 隻薊馬誤判為蚜蟲），源於兩者在低解析度下外觀長寬比與顏色具相似性。

## 7. 結論與限制

1. **推論置信度閾值設定**：依據 F1-Confidence 曲線，建議線上推論部署時將全域置信度閾值設定於 **0.285**，以取得 Precision 與 Recall 的最佳平衡（F1 = 0.79）。
2. **背景偽陽性抑制策略**：針對介殼蟲高達 615 例背景誤判，建議提高背景負樣本採樣比例或調高分類損失權重（`cls: 1.0 ~ 1.2`）。
3. **微小目標特徵改善**：針對薊馬漏檢問題，後續版本可著重於標註尺度重整（如 v5r）以消除標註雜訊。

本報告未涵蓋：獨立測試集（Test Split）評估數據（v8 訓練階段僅劃分 Train/Valid，尚未建立獨立 Test 集）；跨資料集版本（如 v5r）遷移驗證。
